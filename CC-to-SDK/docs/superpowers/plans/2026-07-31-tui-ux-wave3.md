# TUI/UX Sprint Wave 3 (U6 + U7) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use doperpowers:subagent-driven-development (recommended) or doperpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/add-dir` (U6) and the settings surfaces `/config` · `/permissions` · `/theme` · `/output-style` · `/keybindings` (U7) in the ccx REPL, with real Claude Code 2.1.220's copy, keys, and structure wherever our engine can honor them.

**Architecture:** The REPL always talks to the harness host over the loopback/attach wire, so every engine-backed capability lands as the full chain: zod op (`src/host/ops.ts`) → server dispatch (`src/host/server.ts`) → host handler (`src/host/host.ts`) → session method (`src/session/session.ts`) → remote client (`src/client/chatAdapter.ts` + `src/host/wire.ts` reply passthrough) → REPL. Probe 75 proved the two engine doors: the untyped `request({subtype:"register_repo_root"})` funnel (subdir-of-cwd only) and the **typed** `applyFlagSettings({permissions:{additionalDirectories}})` for out-of-cwd grants; probe 76 proved `applyFlagSettings({outputStyle})` takes effect the very next turn. Theme and keybindings are pure client features. Client prefs persist in `~/.claude/ccx/prefs.json`; "remember" writes for add-dir/output-style go to the project's `.claude/settings.local.json` exactly like upstream (the engine reads that file natively at next launch).

**Tech Stack:** TypeScript ESM (`.js` specifiers), Ink (REPL), zod/v4 (ops), vitest (unit + gated live), python pty driver (`scripts/drive-repl.py`) for acceptance.

```ts
// W3 T1: the host OWNS the dynamic flag-settings state. applyFlagSettings replaces whole top-level
// keys per call (probe 75), and a resumed session is a NEW CLI process with an empty flag layer —
// both make a client-side "just call the engine" design wrong. Single accumulator, always sent whole.
private flagPerms = { allow: [] as string[], ask: [] as string[], deny: [] as string[], additionalDirectories: [] as string[] };
private flagOutputStyle?: string;

private async pushFlagPerms(next: typeof this.flagPerms): Promise<void> {
  await this.session?.applyFlagSettings?.({ permissions: { ...next } });
  this.flagPerms = next;                       // commit only after the engine accepted (retry-safety)
}
async addDir(path: string): Promise<void> {
  if (this.flagPerms.additionalDirectories.includes(path)) return;
  await this.pushFlagPerms({ ...this.flagPerms, additionalDirectories: [...this.flagPerms.additionalDirectories, path] });
}
async removeDir(path: string): Promise<void> {
  await this.pushFlagPerms({ ...this.flagPerms, additionalDirectories: this.flagPerms.additionalDirectories.filter((d) => d !== path) });
}
async addRule(behavior: "allow" | "ask" | "deny", rule: string): Promise<void> {
  if (this.flagPerms[behavior].includes(rule)) return;
  await this.pushFlagPerms({ ...this.flagPerms, [behavior]: [...this.flagPerms[behavior], rule] });
}
async removeRule(behavior: "allow" | "ask" | "deny", rule: string): Promise<void> {
  await this.pushFlagPerms({ ...this.flagPerms, [behavior]: this.flagPerms[behavior].filter((r) => r !== rule) });
}
async setOutputStyle(style: string): Promise<void> {
  await this.session?.applyFlagSettings?.({ outputStyle: style });
  this.flagOutputStyle = style;
}
listDirs(): { path: string; source: "cwd" | "launch" | "session" }[] {
  return [
    { path: this.cwd, source: "cwd" as const },
    ...(this.config.additionalDirectories ?? []).map((d) => ({ path: d, source: "launch" as const })),
    ...this.flagPerms.additionalDirectories.map((d) => ({ path: d, source: "session" as const })),
  ];
}
/** Called from INSIDE swapEngine (src/host/host.ts:304) after the new engine session is live —
 *  swapEngine is the single seam both resumeSession (line 337) AND rewind (line 491) go through,
 *  and the new CLI process starts with an empty flag layer. */
private async replayFlagState(): Promise<void> {
  const hasPerms = Object.values(this.flagPerms).some((a) => a.length);
  if (hasPerms) await this.session?.applyFlagSettings?.({ permissions: { ...this.flagPerms } });
  if (this.flagOutputStyle) await this.session?.applyFlagSettings?.({ outputStyle: this.flagOutputStyle });
}
```
