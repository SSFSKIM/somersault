# T-SNIFF Implementation Plan — sniff-derived media type

> **For agentic workers:** REQUIRED SUB-SKILL: doperpowers:subagent-driven-development, one fresh
> implementer per task. Spec: `docs/superpowers/specs/2026-08-26-bl5-linkopen-sniff-design.md` (§T-SNIFF).
> Evidence base with exact code excerpts per chain: `.doperpowers/sdd/2026-08-26-bl5-round/research-sniff.md`
> — every implementer should read its section for the file they touch.

**Goal:** every image-validation chain derives `media_type` from a byte sniff (canon 2.1.246 parity),
making the API's mismatch-400 unreachable; plus fix `admitBytes`'s PNG/JPEG-only sniff gap.

**Architecture:** one new pure helper in the zero-import leaf `src/media/imageDims.ts`; the authoritative
seam (`checkImageBlock`) and the client pre-check (`stageBlocks`) overwrite the declared type with the
sniffed one; `admitBytes` re-homes its ad-hoc derivation onto the helper and widens to four formats.
Chains 3 (appserver registry) and 5 (host staging) inherit chain 1 — pinned by tests, no code.

**Global constraints** (verbatim from spec/house rules):
- `imageDims.ts` IMPORTS NOTHING — test-enforced; the helper must not break that.
- Helper signature: `sniffImageMediaType(buf: Buffer): "image/png" | "image/jpeg" | "image/gif" | "image/webp" | null`; miss returns `null`, never throws. It is a VERBATIM transcription of canon's `b()`
  (research-sniff.md offset 184,082,132 — the excerpt is quoted there): prefix-only. `null` if `length<4`;
  PNG `[137,80,78,71]`; JPEG `[255,216,255]`; GIF length≥6 `GIF87a|GIF89a`; WebP `RIFF`+length≥12+`WEBP`@8-11.
  Do NOT reuse the dimension readers as discriminators — dims validity stays a SEPARATE downstream check.
- Derive semantics: sniffed value OVERWRITES declared; sniff `null` → existing unreadable-image refusal
  path unchanged; allowlist (`IMAGE_MEDIA_TYPES`) applies to the SNIFFED type. No second decode.
- Commands from `harness/`: `npm run typecheck`, `npm run test:unit`, targeted `npx vitest run test/unit/<file>`.
  NEVER bare `npm test`. Commit per task, no Co-Authored-By.
- Real image fixtures live in `test/fixtures/images/` (PNG/JPEG/GIF/WebP from bl4) — reuse, don't synthesize.
