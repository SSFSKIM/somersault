# F9 T-IMAGE Implementation Plan — image paste (Ctrl-V)

> **For agentic workers:** REQUIRED SUB-SKILL: Use doperpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ctrl-V pastes a clipboard image as an `[Image #N]` chip that submits as a base64 image content block the model demonstrably reads; image blocks render as `[Image #N]` rows across every transcript surface.

**Architecture:** Task 1 (I4) is a **standalone projection commit** other tracks depend on. Then: a clipboard-reader leaf module (canon's tier-2 shell quartet + darwin `sips` re-encode ladder), the composer's `PastedEntry` image variant, and the `UserTurnInput` widening through the in-process submit chain with wire-capped paths refusing explicitly.

**Tech Stack:** TypeScript ESM, vitest; `osascript`/`sips` (darwin, no new deps); probe-113-verified SDK wire shape.

**Spec:** `CC-to-SDK/docs/superpowers/specs/2026-08-22-f9-wave-design.md` (Track T-IMAGE). Research: `.doperpowers/sdd/2026-08-22-f9-wave/r4-image-paste.md` (canon cites: quartet L333974-334031, handler L607367-607381, chip L178829/178835, limits L174695-174696, wire block L231272, assembly L371395-371427, transcript rows L528790/L522876/L526971).

## Global Constraints

- Wire shape exactly: `{ type: "image", source: { type: "base64", media_type, data } }`; user message assembly **text block first, image blocks appended**.
- Limits: 2000×2000 px, 5 MiB base64 input, **512,000-byte post-processing per-block ceiling**, 5 MiB aggregate image base64 per turn. Failure degrades to the text block `[Image could not be processed: <reason>]` — never an error, never a dropped turn.
- Image base64 must NEVER be written to `history.jsonl`, stash, or paste caches; labels only.
- v1 transport scope: in-process submits only (foreground REPL, detachable host's composer, library). `ccx attach` / app-server peers refuse image entries with an explicit notice (frame caps: `host/server.ts` MAX_FRAME, `appserver/peer.ts` MAX_IN).
- SECURITY: never print/echo/log the OAuth token or API key; live cells load env via `set -a; . ../.env; set +a`.
- Commands from `CC-to-SDK/harness/`. Never bare `npm test`. Commit per task, no `Co-Authored-By`, never push.
