# bl9 T-FOLLOW Implementation Plan — anchorless `rewound` replay on follow()

> **For agentic workers:** REQUIRED SUB-SKILL: doperpowers:subagent-driven-development, task-by-task.
> Steps use checkbox (`- [ ]`) syntax.

**Goal:** A client that attaches to a `SessionHost` after an in-place rewind/clear learns the
transcript was replaced: `follow()` replays a retained, anchorless `rewound` frame.

**Architecture:** One retained boolean on the host set at the live `rewound` push site; one replay
site in `follow()` before the closing `state`; wire type widened additively; the app server ignores
the stamped replay; the fake-host test stand-in's pre-follow drain narrowed to production
semantics; the refuted `decision_settled` half pinned by a guard test.

**Tech stack:** TypeScript ESM (`.js` specifiers), vitest, DI fake sessions (no network).

**Spec:** `CC-to-SDK/docs/superpowers/specs/2026-08-31-bl9-followreplay-polish-design.md` (§3, A1-A5, A8).
Research: `.doperpowers/sdd/2026-08-31-bl9-round/research-follow-replay.md` (R1 — cite it for any
"why", it carries file:line evidence for every claim below).

## Global Constraints

- Work from the worktree branch `bl9-t-follow`; commit per task, imperative messages, NO Co-Authored-By.
- All commands from `CC-to-SDK/harness/`. Gates per task: `npm run typecheck` + the named vitest files.
  NEVER bare `npm test`.
- Dense hand-style, no Prettier; match surrounding comment density and idiom.
- The replayed frame is **anchorless**: never `prevUuid`, never `cleared` (spec D2 — replaying an
  anchor truncates legitimately-added post-rewind history; `cleared` clobbers a re-populated id).
- The gate is the live-push site, not "any swap": `swapped` flips true exactly where
  `host.ts` emits the live `rewound` (currently `host.ts:660`, the last line of `swapEngine`).

```ts
it("replays an anchorless rewound to a late follower after a swap — before the closing state", async () => {
  // drive: host with fake session; complete a swap that emits a LIVE rewound carrying an anchor
  // (rewind with prevUuid), THEN follow.
  const got: HostEvent[] = [];
  host.follow((ev) => got.push(ev));
  const kinds = got.map((e) => e.kind);
  const rIdx = kinds.indexOf("rewound"), sIdx = kinds.lastIndexOf("state");
  expect(rIdx).toBeGreaterThanOrEqual(0);
  expect(rIdx).toBeLessThan(sIdx);                        // before the closing state
  const r = got[rIdx] as Extract<HostEvent, { kind: "rewound" }>;
  expect(r.replay).toBe(true);
  expect(r.prevUuid).toBeUndefined();                     // anchorless even though the live push had one
  expect(r.cleared).toBeUndefined();
});
it("a never-swapped host replays no rewound", async () => {
  const got: HostEvent[] = [];
  host.follow((ev) => got.push(ev));
  expect(got.some((e) => e.kind === "rewound")).toBe(false);
});
```

```ts
// A joiner whose disk read predates an in-place rewind renders discarded turns forever: the id
// did not move (probe 37b) and `state` only syncs permissionMode. Anchorless on purpose — see
// wire.ts. Gated on a live rewound having fired, so the common never-swapped host pays nothing.
if (this.swapped) { const sid = this.currentSessionId(); this.deliver(cb, { kind: "rewound", ...(sid ? { sessionId: sid } : {}), replay: true }); }
```
