# F9 T-RESUME Implementation Plan — the full-screen rendered transcript view (D-W9)

> **For agentic workers:** REQUIRED SUB-SKILL: Use doperpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Space/Ctrl+V in the session picker replaces the picker wholesale with canon's transcript view: real renderer, detail-all projection, tail-anchored window, top-border-only footer, Enter/`y` resume with the loaded payload, Esc/`n` back — no frame, no header, no in-view scrolling.

**Architecture:** `SessionPicker.tsx`'s preview stage stops rendering inside `PickerFrame` and returns a new `ResumeTranscriptView` component instead; `sessionPickerModel.ts` gains a tagged load state and a detail-all projection path; `bindings.ts` adds `ctrl+v` and the `y`/`n` confirmation keys. Reuses `replayDocument` + `toolRenderer` projections + `RenderItemView` + `wrapItemsToWidth`; deliberately does NOT reuse `TranscriptPager`/`RegionPager` (spec: canon has no scroll keys, no hint row, no region sizing here).

**Tech Stack:** TypeScript ESM, Ink, vitest + ink-testing snapshots.

**Spec:** `CC-to-SDK/docs/superpowers/specs/2026-08-22-f9-wave-design.md` (Track T-RESUME). Research: `.doperpowers/sdd/2026-08-22-f9-wave/r3-resume-view.md` (canon cites: trigger L584023, takeover L584057-584059, view `yvc` L583551, footer L583614-583622, render caps L563246-563388, loading L583604-583606, confirm L583581/583594).

**Dependency:** merges only after T-IMAGE's **I4 standalone projection commit** is on main (image rows `[Image #N]`); acceptance cell 5 reads the merged tree.

## Global Constraints

- Canon-exact non-goals (building them is a defect): in-view scrolling, `g`/`G`, Ctrl-U/D, in-view search, scrollbar, `↑ N more above` line, alt-screen takeover, header/title row, `(no messages)` on a successfully loaded empty session.
- Footer strings verbatim: row 1 `<relative> · N messages[ · <branch>]` (plain), row 2 `enter to resume · esc to cancel` (dim) — row 2 is the existing `PREVIEW_FOOTER` constant, reuse it.
- Window arithmetic: `budget = fullscreen ? min(200, overlayRows()) : 200` collapsed items, tail-anchored, fed from at most `2×budget` raw messages.
- Tagged preview state `loading | loaded(messages) | failed(error)`; only `failed` renders failure copy; confirmation resumes **with the loaded payload** (no re-read-and-reject).
- Commands from `CC-to-SDK/harness/`. Never bare `npm test`. Commit per task, no `Co-Authored-By`, never push.
