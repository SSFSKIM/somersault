# T-QY Implementation Plan (bl8) — standalone hook rows + live counter + clause-form activation

> **For agentic workers:** REQUIRED SUB-SKILL: Use doperpowers:subagent-driven-execution to implement this
> plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render every hook pair the wire delivers: unclaimed/non-PreToolUse pairs as canon's standalone
`Qy` rows, in-flight hooks as canon's `di` live line, and hooks on all-silently-absorbed runs through the
cluster's collapsed clause form (bl7's pinned "latent" branch, now proven reachable — R3).

**Architecture:** The bl7 `HookPairTracker` widens to retain all five reachable events (PreToolUse,
PostToolUse, Stop, UserPromptSubmit, SessionStart) with `event`/`exitCode`/`stderr`, and counts in-flight
hooks per event. `segmentRuns` keeps PreToolUse-only cluster absorption (filter inside `resolveRunHooks`)
and gains a drain: unclaimed entries become `{kind:"hooks"}` FoldItems at run-open/flush boundaries,
label-grouped (canon's coalescing), parked after the cluster via the existing `deferred` list. `flush`'s
emit gate gains `|| hooks non-empty` (D5 — the clause form's true producing shape). The renderer adds
shape 1 (labeled) and shape 2 (Stop, errors-only) rows plus the live counter read from the tracker.

**Tech Stack:** TypeScript, Ink, vitest (`npm run typecheck` / `npm run test:unit` / `npm run test:tui`
from `CC-to-SDK/harness/` — NEVER bare `npm test`), tmux pty cells (`scripts/hookblock-cells.sh`).

**Governing docs:** spec `docs/superpowers/specs/2026-08-30-bl8-qy-advisor-design.md` §1-2 (D1-D6);
canon excerpts: bl7 `.doperpowers/sdd/2026-08-30-bl7-round/research-hookblock.md` §A5/A6 (Qy shapes
verbatim, di verbatim); bl8 `.doperpowers/sdd/2026-08-30-bl8-round/research-silentrun-hooks.md` (D5
evidence) and `research-p119-hook-census.md` (wire shapes); R1 notes §4 (vn/ju/addMargin/coalescing).

## Global Constraints

- Canon copy exact — shape 1: `"  ⎿  "` + `Ran {N} {label} {hook|hooks}` (count NOT bold, NO duration on
  the header, all dim); per-hook lines `"     ⎿ "` + `{hook_name} ({s})` (wire divergence D3: hook_name,
  not command text), gated on `options.projection !== "compact" || options.verbose === true` (D21
  predicate family). Shape 2 (Stop): `⏺ Ran {N} stop {hook|hooks}` count BOLD, then
  `"  ⎿  Stop hook error: {text}"` per failed entry; renders ONLY when at least one entry failed
  (`exitCode !== 0`) — a clean Stop run renders nothing (canon's early exit).
- Durations `(ms/1000).toFixed(1)+"s"` — the bl7 hook formatter, never the general one.
- Labels are the `hook_event` value (`"PostToolUse"`, `"UserPromptSubmit"`, `"SessionStart"`); the
  matcher suffix stays only in per-hook lines. Same-label entries in one drain window coalesce into ONE
  row (counts sum) — canon R1 §4(d).
- Cluster absorption stays PreToolUse-only (canon `jar`); the ONE consumption ledger (`hookClaims`)
  covers both sinks — an entry claimed by a cluster never renders standalone and vice versa (D1/D2,
  bl7 F2's rule).
- D5 emit gate: `run.memberIds.length > 0 && (run.visibleMembers > 0 || hooks.infos.length > 0)`;
  resolve hooks BEFORE the visibility test. Hookless all-silent runs still emit nothing. Rewrite the
  `toolFold.ts:640-643` divergence comment (it is now parity-for-hookless, gap-closed-for-hooks; cite
  research-silentrun-hooks.md).
- Live counter (D6): counts started-without-response per event from the tracker (NOT hook_progress —
  recorded divergence); non-Pre/Post events render `Running {Event} hook…`/`hooks…` (dim, event bold)
  while count > 0; Pre/PostToolUse render `{N} {Event} {hook|hooks} ran` (dim, label bold) only under
  the D21 predicate. Never in the append-once Static region (bl7 D20's rule).
- Hooks stay live-only: cleared on rebuild, absent on resume/attach (bl7 A4 divergence, already pinned).
- `hook_progress` frames are accepted as no-ops (liveness only; stdout NOT displayed — canon's `di`
  shows none either).
- SessionEnd is dead on the wire (P119) — no code path for it.
- Dense hand-style, no Prettier; ESM `.js` specifiers; projection stays clock-free (stamp at ingest).
