**Goal:** make `harness/scripts/fake-host.mjs` honor the real host's replay-on-follow contract, then
delete the `warmup_follow` workaround from the pty drivers so cells exercise the true first push.

**Architecture:** the real `SessionHost.follow()` (`src/host/host.ts:730-772`) drains buffered
history into a late joiner BEFORE registering it, so a frame published pre-follow is never lost. The
fake host's stdin push path fans out to an empty `followers` set with no buffer. Fix: buffer while
`followers.size === 0`, drain on the FIRST follow (marked `replay: true`), drain-before-register.

**Tech stack:** Node (plain .mjs test script), vitest integration test, tmux pty driver (bash).
